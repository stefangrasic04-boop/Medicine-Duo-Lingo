# MEDIQ — Znanje za življenje

Slovenski izobraževalni MVP za zdravstveno pismenost, od osnov do medicine PRO. Šest modulov, 16 vprašanj, razlage, XP, streak in ponavljanje napak.

## Zagon
Odpri `index.html` v brskalniku. Brez zunanjih odvisnosti in strežnika.

## Objava na GitHub Pages
V Settings → Pages izberi Deploy from a branch, vejo `main`, mapo `/ (root)` in Save. Po uspešni objavi bo povezava prikazana v nastavitvah Pages.

## Omejitve
Napredek je lokalen (localStorage); ni računov ali sinhronizacije. Vsebina je demonstracijska in potrebuje neodvisen strokovni pregled. Ni namenjena diagnosticiranju ali zdravljenju.
